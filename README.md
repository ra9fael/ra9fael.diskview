# Disk View QML（ra9fael.diskview.qml）

**简体中文** · [English](README.en.md)

Win顺 的 QML 磁盘占用分析插件。用方块图或圆盘查看空间分布，悬停辨认完整路径，单击固定详情，双击进入目录。NTFS 整盘支持按需授权的快速扫描，其他路径使用普通扫描。树按占用降序，文件列表可独立排序；右键支持路径、文件和删除操作。输入查询本身不会扫描。

## 安装和更新

1. 从仓库 Release 或本地 dist/ 取得 **ra9fael.diskview.qml-0.3.6.wsplugin**。可用旁边的 .sha256 与 PowerShell 的 Get-FileHash 命令核对。
2. Win顺 → 设置 → 插件 → 已安装 → 添加插件 → 压缩包，选择安装包。
3. 本地安装后打开插件开关并确认权限。更新时选择同一 id 的新版安装包，宿主会询问是否替换，并保留插件数据目录。
4. 0.2.0 新增 `files:write`，用于回收站和永久删除；升级时请确认新增权限。0.3.0 增加主题设置、紧凑行高、自动层级和面板标题栏控制；0.3.1 改进对比度、列宽、磁盘菜单和图表导航；0.3.2 修复宿主主题角色、Dock 重拆分和固定表宽列调整；0.3.3 修正筛选、扩展名高亮与 Dock 控件交互；0.3.4 修复根目录操作、列宽拖动、菜单移出关闭和短面板布局；0.3.5 切换磁盘改为下拉框，配色对齐 WinShun 默认主题；0.3.6 修复下拉框文字截断、滚动条闲置淡出、Dock 重复标题与树视图默认列宽，并在支持时启用 Mica 背景。

新版增加 **processes** 权限，用于启动短生命周期的扫描助手；管理员授权仍由 Windows 单独询问。卸载在宿主插件列表中完成。本插件是原生 exe，不属于只收录脚本插件的社区索引。

## 使用

| 操作 | 行为 |
| --- | --- |
| disk | 显示固定磁盘容量；选择磁盘打开窗口并扫描，选择“打开磁盘透视”进入欢迎页 |
| disk D:\工作 | 打开窗口并扫描指定目录 |
| 单击方块、扇区或列表行 | 选中条目，底部详情保持；图表与列表同步高亮 |
| 双击目录 / Enter / “进入文件夹” | 浏览该目录；双击文件只保留详情 |
| 悬停 | 立即显示底部完整路径，约 250 ms 后显示浮层 |
| 顶部面包屑 | 跳到祖先目录；长路径保留根、父级与当前级 |
| 后退 / 前进 / 上一级 | 分别回放浏览历史或返回父目录 |
| Ctrl+L | 编辑地址；Enter 定位已索引目录，未索引路径显示明确的“扫描此路径”按钮 |
| 当前层 / 最大文件 | 查看当前目录的文件与文件夹，或当前子树中最多 1000 个最大文件 |
| 筛选 / 名称和大小表头 | 在当前列表中检索、排序；最大文件模式只筛选该排名中的条目 |
| 定位到所在目录 | 从最大文件列表返回文件所在目录，并保留选中状态 |
| 方块 / 圆盘 / 展开层级 | 默认一层，可看两层；小项合并为“其他 N 项”，点击后在列表展开 |
| 拖动中间分隔条 | 调整图表和列表比例；窄窗口切换图表 / 列表 |
| 扫描问题 / 逻辑大小 | 查看读取失败、大小未知、未归属记录、跳过链接及统计口径 |

键盘支持 Alt+Left / Right 浏览历史，Backspace 或 Alt+Up 返回父级，F6 / Shift+F6 在图表和列表间切换焦点，Ctrl+F 进入筛选，Ctrl+K 搜索操作，Ctrl+C 复制完整路径，Ctrl+Shift+C 复制文件，Ctrl+Shift+X 剪切文件，方向键在图表中按屏幕位置选择邻近条目、在列表中上下移动，Tab / Shift+Tab 切换控件，Enter / Space 激活焦点按钮，+ / − / 0 缩放或适合窗口，Shift+F10 打开条目菜单，Delete 确认移至回收站，永久删除没有快捷键（右键菜单中选择，并输入条目名确认），F1 查看完整快捷键，F5 打开扫描设置。文本框中的编辑按键保持原意。Esc 关闭工具窗口、退出地址编辑或清空筛选；Alt+F4 关闭窗口。

窗口默认跟随宿主配色，也可在窗口内切换深浅主题。插件设置 defaultView 决定初始图表。扫描设置（扫描方式、并发上限、介质策略、预览间隔、下轮排除）与上次扫描路径一起保存在插件数据目录，下次启动恢复。

## 扫描模式与结果

- **固定 NTFS 整盘**：扫描方式在扫描设置中选定。自动模式对整盘 NTFS 使用快速扫描；也可固定为快速或普通。快速模式只为独立助手申请管理员权限，主窗口保持普通权限；拒绝 Windows 授权或助手失败时自动回退普通扫描，并显示原因。
- **文件夹、其他文件系统和 UNC**：使用普通目录枚举，支持长路径。不跟随目录重解析点。普通扫描使用有界目录工作池，并发上限可在扫描设置中调整；并发更高不承诺更快。
- **扫描中**：显示已发现条目、字节数、耗时和当前路径，不编造完成百分比或 ETA。可暂停 / 继续。上次完整结果可继续浏览，也可切换到本轮局部结果。
- **取消或失败**：优先恢复上次完整结果。首次扫描只有部分数据时保留并明确标记“未完成”；失败原因可在扫描问题中查看。
- **快照范围**：完整及局部快照仅保存在当前窗口内存中，尚未实现跨次启动的快照缓存或 USN 增量更新。

快速模式读取 MFT 文件名及未命名 $DATA 的逻辑大小，不读取文件内容或 ADS 内容。硬链接按可见路径计数；目录链接不展开；无法确定的大小显示“未知”。扫描不是卷的事务快照，期间发生的变更可能造成遗漏或差异。系统元数据、命名数据流与无法读取区域并不保证全部纳入用户文件合计。

图表按逻辑大小绘制，中文单位采用 1024 进制。按簇取整的占用只是近似值，不能当成稀疏文件、压缩文件或硬链接的真实物理占用，文件合计也不等于卷的“已用空间”。局部结果的占比以当前已发现内容为基准。

## 权限与数据

| 权限 | 用途 |
| --- | --- |
| ui | Win32 / GDI 独立窗口 |
| files:read | 读取目录和文件系统元数据 |
| files:write | 仅在用户确认后把所选条目移至回收站，或按两步确认永久删除 |
| clipboard:write | 把所选条目以 CF_HDROP 复制或剪切到剪贴板，供资源管理器粘贴 |
| processes | 启动同一 exe 的独立扫描助手；受限本地管道只传输元数据 |

扫描本身只读，不读取文件内容、不联网、不安装服务或自启动。写入动作只有两个，都由用户在右键菜单明确选择并确认：其一，经 IFileOperation 交给系统回收站；其二，“永久删除”不经过回收站，需要先阅读警告、再输入条目名称确认，无法撤销。系统受保护项及其后代不提供删除操作，失败时保留条目并显示原因。复制 / 剪切文件只是把路径以 CF_HDROP（及 Preferred DropEffect）写入剪贴板，由资源管理器完成实际粘贴。插件把上次扫描路径和扫描设置写入宿主插件数据目录的 diskview.json；窗口关闭后释放扫描树。管理员助手退出或连接中断后结束，不常驻。

## 构建与本地预览

Windows 10/11 x64，CMake 3.21+，支持 C++20 的 MSVC 或 MinGW-w64。MSVC 构建请先进入 Developer PowerShell。打包和协议测试需要 Python 3.10+。

~~~powershell
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
ctest --test-dir build --output-on-failure
python tools/package.py
Start-Process .\diskview.exe -ArgumentList '--view' -WindowStyle Hidden
~~~

diskview.exe --view "D:\工作" 可在宿主外直接打开并扫描指定目录；不带路径打开欢迎页。预览模式不保存插件配置。正常无参数启动保留宿主所需的 JSON-RPC 协议模式。

回归测试覆盖扫描汇总、取消与不可变局部快照、MFT 元数据解析、硬链接、未知大小、记录序列号、扩展记录、损坏记录及管道消息边界；隐藏窗口测试覆盖选择、导航、筛选、键盘、图表布局和结果恢复。协议测试运行真实插件进程，核对 Unicode 路径、主题更新、重复打开与退出。

运行 tools/verify/render-views.ps1 生成 build/verify/ 下的原生窗口截图。开发验证脚本不放入安装包。实现状态与本机测量记录见 [implementation-status.md](design/implementation-status.md)。
