# Disk View（`ra9fael.diskview`）

> **简体中文（默认）** · [English](README.en.md)
>
> Win顺 默认使用中文界面，也自带英文模式。因此中文说明放在 `README.md`，
> 英文说明放在 `README.en.md`，两份内容保持一致，可互相跳转。

给 Win顺 用的磁盘占用可视化插件：扫描任意文件夹后，用**递归矩形图（treemap）**
或**递归放射圆盘（sunburst）**看空间都花在哪里。面积即体积——越大越占地方；
悬停看明细，点击下钻，右上角常驻"最大的文件"榜单。查询不扫描：扫描只发生在
窗口里、由你触发，插件不会在每次键入时碰文件系统。

## 安装

1. 从 [最新 Release](https://github.com/ra9fael/winshun-diskview/releases/latest)
   下载 `ra9fael.diskview-<version>.wsplugin`。可选：用旁边的 `.sha256` 文件核对
   SHA-256（`Get-FileHash <file> -Algorithm SHA256`）。
2. 在 Win顺 里打开 **设置 → 插件 → 已安装 → 添加插件 → 压缩包（.zip / .wsplugin）**，
   选中该文件。
3. 从本地安装包安装的插件**不会自动启用**。请在列表里打开开关；启用这一步就是你
   在确认它申请的权限（见 [权限与数据](#权限与数据)）。

**更新：** 用同样方式安装新版的 `.wsplugin`。Win顺 认出是同一个 id，会先询问是否
替换旧版本，并保留插件的数据目录。

**卸载：** 在 **设置 → 插件 → 已安装** 里移除。

本插件是原生 exe，不会出现在 Win顺 应用内的插件库里（社区索引只收脚本插件）。
本仓库的 Release 是唯一的分发渠道。

## 使用方法

在 Win顺 输入框输入 `disk` 后回车，打开磁盘透视窗口：

| 输入 | 行为 |
| --- | --- |
| `disk` | 打开窗口。首次使用为欢迎页；之后再打开会记住上次扫描的路径 |
| `disk D:\工作` | 打开窗口并**立即**扫描 `D:\工作`（这是你主动触发的唯一扫描入口） |

窗口内操作：

- **路径框 + 扫描**：输入任意文件夹路径回车或点"扫描"开始；扫描中按钮变为
  "停止"，点击即取消（取消后保留上一次完整结果，不显示半成品）。
- **递归矩形 / 递归圆盘**：两种画法随时切换（快捷键 Ctrl+V）；默认画法可在
  插件设置里改（`defaultView`）。
- **下钻 / 返回**：点击方块或扇区进入该文件夹，点"返回"或 Backspace 上层，
  点状态栏面包屑跳任意祖先层。
- **最大的文件**：右侧榜单列出当前范围下最大的文件（默认 64 条），点击行
  跳到其所在文件夹；滚轮翻页。
- **悬停**：任意方块 / 扇区显示类型、大小、文件与文件夹计数、无法读取项数；
  文件还会给出按簇对齐后的占用近似。
- **Esc** 关闭窗口；**F5** 重新扫描当前路径。

## 两种视图

- **递归矩形图（默认）**：squarified treemap。文件夹继续向内嵌套细分，文件
  是叶子方块，颜色按扩展名分类（视频 / 压缩包 / 图片 / 文档……），同色系
  保持稳定。太小的条目（低于 24 dpi 像素）不再绘制——被省略的空间留白，
  父节点面积仍代表其真实总量，不会把小项的体积"摊"到大块上。
- **递归放射圆盘**：从内到外的同心环，内层是文件夹、外圈是它的子项，角度
  即占比。小于 0.003 弧度的扇区省略，同样只留空隙、不改总数。

## 从源码构建

环境要求：Windows 10/11 x64、CMake 3.21+，以及 Visual Studio 2022 及以上（MSVC）
或 MinGW-w64 GCC 13+。打包和集成测试需要 Python 3.10+。

```powershell
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release   # MSVC；MinGW 用 -G "MinGW Makefiles"
cmake --build build                                       # 在 plugin.json 旁边生成 diskview.exe
ctest --test-dir build --output-on-failure                # 纯逻辑测试（布局 / 扫描 / 路径规范化）
python tools/package.py                                   # 生成 dist/<id>-<version>.wsplugin
```

纯逻辑测试覆盖：treemap 面积守恒与比例、剔除小项后的留白、sunburst 角度连续
与嵌套半径、真实临时目录上的扫描汇总（含"最大的文件"排序）、取消语义、无效
路径报错、`\\?\` 长路径与 UNC 前缀规范化。

## 权限与数据

| 权限 | 用途 |
| --- | --- |
| `ui` | 打开独立的扫描窗口（Win32 + GDI，无第三方依赖） |
| `files:read` | 扫描时枚举目录与文件元数据（FindFirstFile），只读，不打开文件内容 |

- **不申请**管理员提权、网络、剪贴板、开机自启等任何其他权限。
- 扫描只读元数据：大小、时间戳、目录树结构。文件内容不会被读取，更不会
  上传——插件没有任何网络代码。
- **数据位置**：插件把窗口偏好（上次扫描路径、视图选择）存在 Win顺 给每个
  插件分配的数据目录里的 `diskview.json`（约几十字节）。除此之外不写任何
  文件，不碰注册表。
- 卸载插件时该数据目录随 Win顺 的插件数据一起清理。

## 失败与边界处理

- 路径不存在 / 不是文件夹：窗口内容区给出错误说明，不显示旧数据。
- 无法读取的目录（系统权限等）：计入父节点的"无法读取项"，并在状态栏列出
  具体路径（上限 32 条）；不会中断整个扫描。
- 符号链接 / reparse point：计入大小但**永不跟随**，避免环与重复计算。
- 扫描被取消：丢弃半成品树，保留上一次完整结果，状态栏注明"已取消"。
- 超长路径（>260 字符）通过 `\\?\` 前缀支持；UNC 网络路径同样可扫。
