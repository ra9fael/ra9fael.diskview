# Disk View 导航与操作改进方案

日期：2026-11-09。对应原型：`diskview-controls-prototype.html`。

本轮交付是交互设计和可操作的 HTML。原生插件仍是当前工作区版本，本轮未修改其实现、重新安装或发布。原型使用合成数据，不读取磁盘、不提权、不执行文件删除或外部程序。

## 已确认的决策

- 方向操作同时包含：键盘选择条目、放大后四向平移图表。
- 单击选中，双击目录进入。
- MFT 扫描实际很快；保留现有快速路径，不以增加 MFT 读取线程作为本轮改进目标。
- 需要快速整盘扫描时，仅扫描助手按需申请权限；主界面保持普通权限。用户拒绝后回退普通扫描。
- 返回父级必须容易发现，并能连续操作。后退历史和返回父级分别提供。

## 父级导航规则

1. **主入口**：当前位置标题旁常显“↑ 返回 {父目录名}”，不是只放一个箭头。窄窗口独占一行。
2. **就近入口**：目录列表首行固定“.. 返回 {父目录名}”，不参与排序、筛选和分页；圆盘中心显示“返回上一级”和父目录名。
3. **跨多级**：点击面包屑任意祖先；路径过长折叠中间段，通过“全部上级”选择任意祖先。
4. **连续操作**：返回后重新选中刚离开的目录，焦点回到此前的图表或列表；再次 Backspace 可继续向上，Enter 可重新进入。
5. **边界**：扫描根禁用父级入口；不能暗中读取扫描范围之外的目录。若将来需要访问扫描根的上级，应明确提供“扫描父目录”，并说明会启动新扫描。
6. **历史**：Alt+←/→ 浏览访问历史，Alt+↑/Backspace 返回实际父级。两者文案与按钮职责分开。

实现时以稳定节点 ID / 标准化路径保存选择、历史、滚动位置，避免快照更新后继续使用失效的节点指针。原型已演示返回后恢复选择与焦点；原生还需要保留实际列表滚动位置和每目录视图状态。

## 方向键、缩放与焦点

| 所在位置或按键 | 行为 |
| --- | --- |
| 图表 ↑↓←→ | 按屏幕空间选择相应方向的近邻；两层视图优先同层条目 |
| 列表 ↑↓ | 上一项 / 下一项；跨分页仍可连续选择 |
| 列表 ← / → | 返回父级 / 进入所选目录 |
| Enter / 双击目录 | 进入所选目录 |
| Alt+↑ / Backspace | 返回父级 |
| Alt+← / Alt+→ | 历史后退 / 前进 |
| F6 / Shift+F6 | 图表与列表之间切换焦点 |
| Tab / Shift+Tab | 常规控件焦点遍历 |
| + / − / 0 | 图表放大 / 缩小 / 适合窗口 |
| Ctrl+滚轮 | 图表缩放 |
| 空格+拖动 / 中键拖动 | 平移放大后的图表 |
| 图表下方四向按钮 | 平移观察区域；100% 时禁用并提示需放大；不遮挡圆盘标签 |
| 归中 / 适合窗口 | 分别只恢复平移、同时恢复缩放和平移 |

方向键不同时承担选择和平移，避免按一下就失去当前条目。平移设置边界，保证图表不会被全部移出视野。进入其他目录时恢复适合窗口。原生落地时补充选中项自动进入可视区域以及高 DPI 下的命中测试。

输入框焦点下，方向键和 Backspace 保持文字编辑含义。Ctrl+C 在输入框中保持复制文字含义。所有扫描发布均不得抢走地址栏、筛选或菜单焦点。

## 右键菜单与命令

图表与列表的右键首先选中指向的条目，再打开同一套菜单。Shift+F10 对当前选中项打开。支持上下、Home/End、Enter 和 Esc，关闭后恢复原焦点。

菜单包含进入目录 / 查看文件、返回父级、定位所在目录、资源管理器显示、复制完整路径、属性、重新扫描此目录、下轮排除、移至回收站。目录和文件使用符合类型的操作；重扫文件时选择其所在目录。

原生使用统一命令表，集中处理可用条件、标题、快捷键和执行入口。工具栏、菜单、命令搜索均调用同一行为，避免未来出现右键与快捷键执行范围不同的问题。

| 快捷键 | 操作 |
| --- | --- |
| Shift+F10 / 菜单键 | 当前项菜单 |
| Ctrl+L | 编辑已索引目录路径 |
| Ctrl+F | 筛选当前列表 |
| Ctrl+K | 操作搜索 |
| Ctrl+C | 复制选中路径 |
| Alt+Enter | 属性 |
| F5 | 扫描设置 / 重新扫描入口 |
| Delete | 显示移至回收站确认 |
| F1 | 快捷键帮助 |
| Esc | 关闭菜单或对话框、退出地址编辑 |

清理动作需要确认路径、大小和影响范围。系统受保护项及其后代不提供直接清理；原型中的确认和撤销只改变合成数据。原生必须使用系统回收机制，成功后再更新结果，失败时保留项目并显示具体原因；不能把原型的即时撤销暗示为任意真实文件都能无条件恢复。

## 平滑圆盘的实现方案

采用浮点几何圆弧表示扇区的内外边界，统一屏幕变换和反向命中计算；绘制后避免再把节点坐标整数量化。建议用 Direct2D 实现并验证抗锯齿、设备丢失恢复和高 DPI 渲染。文字使用独立排版，圆盘中的小文件优先显示容量，完整名称在悬浮和详情区展示。

圆盘中心保持稳定的父级返回目标；很小的扇区仍可从列表和键盘选中。选中和悬浮使用细轮廓，不用很粗的边框掩盖锯齿。原生验收覆盖 100%、125%、150%、200% 系统缩放，以及图表放大和平移。

HTML 中的 SVG 圆弧仅说明交互与视觉目标，不构成原生 Direct2D 的运行或性能验证。

## 扫描与多线程

### MFT 快速路径

保留现有读取方式。用户已确认 MFT 很快，这轮不需要靠读取线程数解决不存在的速度问题。后续记录读取、解析、构树、发布的分别耗时；若预览构树确实占用较高，再将接收和聚合分开。使用有界队列、批次合并和不可变快照，防止复制树、排序或频繁重绘成为新瓶颈。

### 普通扫描

目录枚举任务进入有界队列，由固定数量的 worker 处理。每个 worker 产出局部结果，统一聚合线程维护大小、排名和错误计数；不要每个目录创建线程，也不要让多个 worker 同时改写同一棵共享树。

自动策略的**待测起点**：SSD 4、HDD 1、网络目录 2；手动上限提供 1 / 2 / 4 / 8。这些数字是原型方案参数，不是通用最佳线程数或性能结论。线程更多不承诺更快。根据磁盘响应、队列长度、内存和 UI 发布成本评估默认值；失败或延迟升高时降低并发。

取消检查贯穿枚举、排队、合并和发布；取消后不得继续提交旧批次覆盖新扫描。暂停应停止发出新目录任务，允许当前系统调用收尾。明确不跟随目录重解析点，保留硬链接和大小口径说明。

测试矩阵：MFT 与普通扫描分开；SSD/HDD/网络分开；整盘与大量小文件目录分开；冷/热缓存分开。记录总耗时、首次可浏览耗时、各阶段成本、峰值内存、取消延迟、UI 长帧和完整性校验。使用相同范围与统计口径比较。

原型的进度为合成演示。并发设置只改变调度显示，不改变动画速度；动画时长不能当成性能数据。

## 结果完整性与其他改进

- 本轮未完成、上次完整和本轮完成分别标注。更新期间默认保留完整结果，允许主动查看已发现内容。
- 等待父子关联的 MFT 记录属于处理中状态，不在扫描中直接记为读取错误。结束后再核对未解决关联。
- 权限拒绝、读取失败、主动排除、重解析点跳过、未知大小和取消分别计数；错误详情附具体路径、原因和重试范围。
- 统计口径、问题与扫描诊断使用非模态面板，任何时候都不挡住父级导航。
- 扫描发布保持浏览路径、选择和输入状态；失败后能查看详情、重试，并保留可用结果。
- 悬浮显示完整路径、大小和占比；状态栏同步完整路径。单击详情面板提供不依赖悬浮的查看方式。
- 窄窗口切换图表 / 列表，桌面可拖动分栏；主题和键盘提示均可体验。

## 原型使用与边界

打开 `diskview-controls-prototype.html` 后默认位于截图对应的深层目录。先尝试标题旁返回按钮，再试列表首行和圆盘中心。右键任意条目或按 Shift+F10；按 F1 查看映射。放大图表后测试四向按钮与空格拖动。

底部提供深层目录、整盘总览、失败 / 未完成和重置演示。扫描设置可体验普通扫描并发、模拟拒绝授权回退、暂停、取消及局部结果切换。数据由预置样本组成，不模拟真实磁盘容量；扫描范围和排除设置演示下一次请求的配置，不能代表真实扫描或实际覆盖情况。复制路径保存在演示剪贴板，资源管理器和文件打开只展示目标说明。

| 优先级 | 工作 | 验收 |

| P0 | 统一命令、右键、快捷键帮助 | 同一项通过菜单和键盘执行结果一致；菜单靠边不越界；关闭后焦点可继续操作 |
