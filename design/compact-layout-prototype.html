快捷键与操作

方向键图表中按屏幕位置选择邻近条目；列表中上下移动
← / →列表焦点下：返回父级 / 进入所选目录
Enter进入目录 / 打开文件
Backspace / Alt+↑返回父级
Alt+← / Alt+→历史后退 / 前进
滚轮图表缩放（指针位置为锚点）
空格+拖动 / 中键拖动平移放大后的图表
0适合窗口（复位缩放与平移）
F6在图表与列表之间切换焦点
Ctrl+L编辑路径（未索引路径需明确触发扫描）
Ctrl+F筛选当前列表
Ctrl+K搜索操作
Ctrl+C复制选中项的完整路径
Ctrl+Shift+C复制文件（CF_HDROP，到资源管理器粘贴生效）
Ctrl+Shift+X剪切文件（粘贴即移动）
Alt+Enter属性
F5扫描设置 / 重新扫描
Delete移至回收站（需确认）
Shift+F10 / 菜单键当前项右键菜单
F1本帮助
缩放与平移不再占用按钮：滚轮、空格拖动和 0 键覆盖同样的能力，屏幕空间全部留给图表。 状态信息合并到底部两行状态栏，路径、大小、占比和操作按钮都在那里。 右键菜单按 文件操作 / 导航 / 扫描 分组；永久删除没有快捷键，需要在菜单里选择并逐字输入条目名称确认。
