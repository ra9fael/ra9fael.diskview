# Disk View 精简布局原型（compact-layout-prototype.html）

日期：2026-11-09。对应原型：`design/compact-layout-prototype.html`。
验收脚本：`build/compact-prototype-check.cjs`；截图与结果：`build/compact-prototype-qa/`。

本原型与 `diskview-controls-prototype.html` 的分工：

- `diskview-controls-prototype.html` 验证**导航与操作模型**（父级三入口、命令表、扫描状态机、非模态面板），使用合成磁盘树。
- `compact-layout-prototype.html` 验证**屏幕空间分配**：把两行图表工具条和整块详情面板折叠成一行工具条加两行状态栏，图表面积从约 60% 提升到约 80%。数据来自一次真实扫描的插件目录（`REAL_SCAN`），因此尺寸和条目名称都是真实值。

## 本轮完成

原型此前只有布局与绘图，交互层留了 toast 占位。本轮补齐：

| 能力 | 实现 |
| --- | --- |
| 统一命令表 | `COMMANDS` 数组同时驱动右键菜单、Ctrl+K 操作搜索和快捷键；可用条件集中在 `commandEnabled()` |
| 右键菜单 | 图表与列表共用；鼠标右键、Shift+F10、菜单键；↑↓/Home/End/Enter/Esc；关闭后焦点回到原处 |
| 属性对话框 | Alt+Enter 或菜单项；类型、完整路径、逻辑大小、占比、文件数、扩展名 |
| 复制路径 | Ctrl+C 或菜单项；写入演示剪贴板并回显 |
| 定位 | 定位到文件所在目录并保持该文件选中，同时切回“当前层”列表 |
| 下轮排除 | 菜单项可切换；状态栏与扫描设置同步显示排除项数 |
| 移至回收站 | 确认对话框列出路径、大小、影响范围；系统受保护路径不提供该操作；删除后可撤销（仅合成数据） |
| 编辑路径 | Ctrl+L 就地编辑；已索引路径直接跳转，未索引路径弹出“路径未索引”并要求明确触发扫描 |
| 悬浮详情 | 约 250 ms 延迟；完整路径、大小、占比、文件数 |
| 读取问题面板 | 非模态，位于右下角，不遮挡父级导航；打开时仍可返回上级 |
| 全部上级 | 路径折叠时点击“…”打开祖先选择器，直接跳转任意祖先 |
| 扫描设置与进度 | 方式 / 介质 / 并发上限 / 预览间隔；普通扫描显示 worker 数；进度明确标注为演示，不代表真实耗时 |
| 键盘焦点 | 按过键后才显示图表/列表焦点框，避免鼠标操作时出现无意义的描边 |
| 复制 / 剪切文件 | 菜单项与 Ctrl+Shift+C / Ctrl+Shift+X；写入演示剪贴板并回显，原生版写 CF_HDROP |
| 永久删除 | 不经过回收站：先读警告，再逐字输入条目名称才能确认；系统受保护项不提供 |
| 分组菜单 | 图表、列表与状态栏共用同一菜单，按“文件操作 / 导航 / 扫描”三组排列 |

## 布局修正

- 窄窗口断点从 `< 760` 改为 `<= 760`，与验收宽度一致。
- 760px 以下图表工具条改为两行：第一行父级按钮与当前目录，第二行视图切换（方块/圆盘、1/2 层、图/列表）。
- 390px 以下状态栏改为三行堆叠：选中项、完整路径、事实与操作按钮；不再挤压成一行。
- 修掉了 390px 下 438px 的横向溢出（导航行与工具条内边距）。
- 图表窗格上下内缩从 8px 收到 4px，与原生一致；1280×860 实测图表 701px，占窗口 81.5%（原约 79%）。
- 瞬时消息从屏幕居中改为图表区右下角的 toast，停留时间与原生一致为 4 秒。

## 边界

- 数据是一次真实扫描的快照，但原型不读取磁盘、不提权、不执行真实文件操作。
- 删除与撤销只改变内存中的合成树；原生必须使用系统回收机制，成功后再更新结果。
- 扫描进度是合成动画，不能当作性能数据；并发设置只改变调度显示。
- 本原型不替代原生插件集成测试，也不构成 Direct2D 渲染或性能验证。
