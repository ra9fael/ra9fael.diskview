# Disk View 0.2.0 实现与验收

本地交付日期：2026-11-09。依据用户确认的 HTML 交互模拟实现原生 Win32 / GDI 界面。本文件记录真实实现；interaction-redesign.md 保留当时的设计分析，diskview-prototype.html 保留合成数据原型。

## 已实现

- 单击选择、双击进入目录；鼠标离开后保留选择；列表和图表互相高亮。
- 即时完整路径状态栏、约 250 ms 延迟的悬浮详情、固定详情及“进入文件夹 / 定位到所在目录”。
- 顶部当前目录面包屑、历史后退/前进、上一级、Ctrl+L 地址编辑；未索引路径要求明确触发扫描。
- 父级导航三处入口（标题旁按钮、列表首行“..”、圆盘中心）与“全部上级”链路；返回后恢复刚离开目录的选中状态与焦点；每目录视图记忆。
- 方块/圆盘、一层/两层、父目录独立标题、小项聚合展开、拖动分隔条、窄窗口图表/列表切换。
- 图表缩放与四向有界平移、空格拖动与中键拖动、适合窗口复位；命中测试计入缩放和平移。
- 当前层文件和文件夹、最多 1000 项的当前范围最大文件排名、名称/大小排序、列表内筛选和分页。
- 统一命令表驱动的右键菜单、操作搜索（Ctrl+K）与快捷键；F1 快捷键帮助；Shift+F10 与菜单键。
- 普通权限主界面、按需管理员 NTFS 只读助手、拒绝授权或助手故障回退普通扫描并显示原因。
- 普通扫描有界工作池、扫描中暂停/继续、扫描设置持久化、下轮排除列表。
- 扫描进度节流；不可变局部结果；旧完整结果可浏览；取消/失败保留旧结果或明确标识的未完成数据。
- 扫描问题详情、未知大小、未归属记录、等待关联记录、主动排除项、统计口径说明；键盘导航；独立 --view 预览入口。
- 移至系统回收站（IFileOperation，拒绝非回收删除），受保护路径不提供该操作。

## 性能实测

2026-11-08 对本机 D: 运行真实快速扫描助手，输出：

~~~text
outcome=0 files=929665 bytes=899033763112 elapsed_ms=3453 unknown=5 orphan=0 reason=
~~~

该次扫描读取 929,665 个文件路径条目，逻辑大小合计 899,033,763,112 字节，用时 3.453 秒；5 项大小未知，0 项未归属。测试入口为 diskview_tests.exe --benchmark-mft D:，经过真实管理员授权。

这是一次本机引擎与进程通信测量。它没有局部预览回调，不包含用户等待授权的时间，也不是包含全部 UI 绘制的端到端测量。未与同权限、同范围、相同缓存条件下的 WizTree 做对照，因此不提供速度提升倍数或普遍耗时承诺。

## 正确性和边界

快速扫描复用 WinShun 的 MFT 只读部分；源提交和 MIT 许可证在 vendor/winshun/ 中。文件引用保留记录序列号，避免错误挂接到复用的父记录；支持扩展记录补充逻辑大小。硬链接按路径计数，目录重解析点不跟随。无法确定的大小保持未知，不当作确认的零字节。

两种引擎都按逻辑大小绘图，簇取整只是占用近似值；不保证命名数据流、全部系统元数据或扫描期间变更都被完整纳入。普通枚举使用有界目录工作池（`parallel_scan.h`）：固定数量的 worker 只做目录枚举并产出局部结果，由单一协调线程合并进树，因此没有多线程同时改写同一节点。自动策略从 SSD 4、机械盘 1、网络 2、未知设备 1 起步，可在扫描设置中改为 1 / 2 / 4 / 8；并发更高不承诺更快。主要的整盘加速仍来自 MFT 路径。筛选范围是当前列表，最大文件模式不是全盘文件搜索。

快照只在当前窗口内存中保留。跨次启动的索引持久化、USN 增量刷新及进一步的百万项内存优化仍属于后续工作。扫描设置（方式、并发、介质、预览间隔、排除列表）与上次路径一起写入插件数据目录的 diskview.json，下次启动恢复。

## 验收范围

- MSVC Release / C++20 编译；CTest 的 diskview_logic、diskview_protocol。
- 布局面积和角度、扫描汇总、取消、不可变局部快照、真实临时目录和 Unicode 路径。
- 并行扫描在 1 / 2 / 4 / 8 个 worker 下与串行结果逐项一致；排除、暂停、取消和回调抛异常。
- 扫描设置写入后读回一致；手改越界值被夹取；设置面板打开时显示已保存的值。
- 合成磁盘记录经过真实 MftReader：硬链接、扩展记录、未知大小、重解析点、失效父记录序列号和损坏记录；管道截断消息检查。
- 原生隐藏窗口：选择与双击、二次点击尾事件、历史和面包屑、筛选、最大文件定位、小项展开、Tab 键盘焦点、失败/取消后恢复。
- 原生截图：欢迎、方块、悬浮提示、两层图、圆盘、深浅主题、窄窗口、144 DPI、扫描状态。
- 独立预览进程、安装包内容和校验和。没有替换宿主已安装版本，没有发布或提交版本库。

测试截图使用合成数据，位于 build/verify/；它们与真实 D: 引擎测量是不同验证。未覆盖所有 NTFS 卷状态、Windows 版本或第三方安全软件环境。
