# 文件视图与菜单交互方案

状态：待审阅。此目录只有设计稿，不修改插件界面。

## 回收操作

`0x00270008` 是 `COPYENGINE_S_DONT_PROCESS_CHILDREN`，属于 Shell 成功状态，不是足以解释回收失败的错误码。目前代码在 `PerformOperations` 返回成功后查询 `GetAnyOperationsAborted`，错误文字可能以最后查询步骤和单项成功状态拼成误导信息。

修复方案：分别保留初始化、排队、执行、单项回调和中止结果；回收成功以确实得到可恢复目标为依据，中止和跳过不拼成“Windows 错误 0x00270008”。53.6 GB 大文件要检查所在卷回收站配置与可用容量，使用新建测试文件验证，不操作用户原视频。容量不足、用户取消、访问拒绝和未知中止分别显示对应信息；容量不足只有得到可靠证据后才明确指出。无法确定原因时显示“Windows 未完成回收，文件仍在原位置”，技术详情折叠显示。永久删除是独立操作，必须另行确认，不自动执行。

## 下拉与显示列

所有下拉面板采用选盘面板的视觉：浅色表面、1 px 边框、4 px 圆角、紧凑行高、统一内边距、整行悬停底色。单选项左侧保留勾选槽，文字左对齐；多选列项目使用复选框，点击后保持面板打开。点击外部、Esc 或再次点击入口关闭；键盘可到达每个项目。

去掉树、文件、扩展名表格右侧独占整列的工具轨道。“显示列”放在列表 Dock 标签组右侧，与最大化按钮同一行，作用于当前激活的列表。标签切到可视化时隐藏此入口。表头右键也打开同一个面板。文件名列始终保留；其余列独立切换，底部“恢复默认列”。窄宽度时入口只显示 PH 图标并保留提示。

预设布局沿用四种排列，菜单明确勾选当前预设；自定义时按钮文字为“预设布局 · 自定义”。

## 扩展名高亮

扩展名选择后，可视化工具栏显示“高亮：.mp4 ×”，关闭按钮名称为“取消扩展名高亮”。扩展名视图同时显示“清除选择”。再次点击已选扩展名也取消。两个入口清除同一状态；在搜索框或弹窗中按 Esc 不清除高亮，避免与现有取消操作冲突。

## 文件工具栏

同一行左对齐，控件高 28 px，间距 8 px，工具栏高 40 px：

`[搜索文件名或路径…      ×] [范围：当前目录 ▾] [匹配：包含文字 ▾]`

搜索框弹性占位，首选宽 300 px；其余控件紧随搜索框，不分散到两端。范围菜单为“当前目录”“当前目录及子目录”“整个扫描”，将原范围和无文字文件夹按钮合并。匹配菜单为“包含文字”“模糊匹配”，分别附“按名称或路径查找”“按文件名中的字符顺序查找”。空搜索时不应用匹配算法，显示范围内全部文件。

窄面板下保持控件高度及顺序，范围和匹配自然换到第二行，工具栏随内容增高；不缩成省略文字。实际映射：当前目录=当前根且不递归；当前目录及子目录=当前根递归；整个扫描=扫描根递归。
