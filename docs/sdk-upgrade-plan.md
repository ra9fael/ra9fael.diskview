# DiskView QML：配置同步与文件夹动作改进方案

[English](sdk-upgrade-plan.en.md)

范围为 `ra9fael.diskview.qml`，发布清单位于 `qmlapp/plugin.json`。

## 改动原因

`qmlapp/src/plugin_main.cpp::settingsChanged()` 当前忽略宿主设置，建窗路径也关闭了同步桥接，导致卡片值与扫描器本地配置可能不同。部分已有文档所述同步行为需要与实现统一。

现有扫描设置对话框已支持高级参数和排除路径，可以复用为独立设置内容。文件夹结果右键动作能直接提供准确目标，省去重新输入路径。

## 界面分工

| 入口 | 内容 |
|---|---|
| 搜索栏 | 打开查看器、选择路径、最近目标和设置入口 |
| 宿主卡片 | 默认视图、扫描方式、文件夹菜单开关 |
| 设置窗口 | 公共配置，以及并发、介质策略、预览频率、小文件聚合阈值和排除路径 |

公共三项由宿主保存；高级扫描项移出清单后由插件保存。最近路径、Dock 布局、列配置、视觉状态和排除路径继续留在本地。

## 实现方案

1. 更新 SDK，在初始化时应用并保留宿主配置，为后续创建的窗口提供初值；更新通过 GUI 线程传到已打开窗口。
2. 设置窗口中公共项恢复可编辑，修改后仅回写变更键；宿主下发不再次回发。
3. 清单高级项移除前保留本地值并转存宿主已有配置。宿主字符串与本地枚举使用同一映射。
4. 区分“默认视图”和现有工作区当前视图。默认值影响下一次打开；浏览时切换视图不隐式修改默认值，设置中提供明确的默认视图控件。
5. 声明 `settingsWindow: true`，将现有设置内容复用于顶层设置窗口，避免仅配置就构建完整查看器或启动扫描。工具栏与搜索入口打开相同内容；lazy 插件保留搜索冷启动入口。
6. 使用草稿和应用／取消。应用仅提交编辑字段，取消不改变配置。参数用于下一次扫描；重新扫描是独立明确选项，无目标时不可用。
7. 增加 `files` 触发：`kind: folder`、`max: 1`，通过布尔设置的 `if` 控制显示。动作读取路径数组，用户执行后才进入已有扫描流程。
8. 保留现有提权和快扫规则，菜单不扩大权限或替换扫描目标。

并发继续使用 `auto / 1 / 2 / 4 / 8` 选择，不提供扫描器不支持的连续值。

## 验收标准

- 宿主扫描方式更新能到达窗口和下一次扫描，窗口公共项能回写宿主。
- 原并发、介质、预览配置在归属调整后保留。
- 仅打开设置不扫描磁盘树；取消不修改，应用不隐式重扫。
- 文件夹菜单按开关显示，只接受一个文件夹，空格与中文路径准确传入。
- 查看器重开及独立运行模式保留原配置行为。
- 隔离数据和小型 fixture 下，相关设置、扫描与协议验证通过。

## 文档更新

更新 QML README 和使用说明，明确双向同步、默认视图、设置归属、文件夹动作及参数在下一次扫描生效的规则。
