# 0.1.18 图表分层 / 选中态 / 列表列宽与网格

分三阶段提交：

1. `7add5e9` feat(qml): layer the treemap by area budget, not a fixed depth
2. `6cd6ff1` feat(qml): draw the selection over the chart, not under it
3. `5976046` feat(qml): give the tables one column model, working grips and a grid

## 1. 图表分层（A）

- 每个文件夹按可用面积取三种形态，不再由固定层级决定：
  - 折叠块：内容区 < 1600 px²，或没有 ≥ 48 px² 的孩子 → 一整块内容色 + 一行 `名称 大小`；
  - 框住：宽 ≥ 64 且高 ≥ 标题条 + 10 → 1px 中性边框 + 顶部标题条，内容留白；
  - 展开：能放下两个 ≥ 48 px² 的孩子 → 子块画在框内。
- 标题条高度随层级 16 / 13 / 11 px，放不下就退回折叠块。
- 结构用中性色：框与标题条取 `chromeFill/chromeInk/chromeBorder`，不再跟色相；规则是"框=结构、色=内容"。
- 被裁掉的子项和导出时被截断的字节合并成一块"其余 N 项"（无节点时显示"其他"），
  文件夹内部始终被内容铺满，父块自身颜色不再露成大色块。
- 色相改为按分支：顶层文件夹按大小用黄金角铺开，往下只在父色系内小幅偏移。
- 层级控件新增"自动"并设为默认（`chartDepth = 0`）：`ChartItem` 用面积预算自行收层；
  1–5 仍是固定上限。`DiskViewModel` 自动时按 5 层导出。
- 顺带修正：图表在独立运行时从不跟随明暗切换；`setTheme` 现在接受宿主的 `dark|style` 串，
  `Main.qml` 用 `window.dark` 绑定（`theme.dark` 在绑定里会指向属性自身）。

## 2. 选中态（B）

- 绘制顺序改为 内容 → 标题条 → 选中层；选中不再被后画的标题条盖住。
- 选中：外 2px 半透明光晕 + 2px 主色环 + 内侧 1px 对比发丝线；选中文件夹的标题条整条换主色并重绘白色/深色文字；
  选中文件在自身块上加 24% 主色蒙层。
- 选中时其余块压暗（浅色 26/255，深色 46/255），选中项所在分支（自身与各级父文件夹）保持原色。
- 悬停只有 1px 主色环 + 35% 光晕，不压暗。
- 选中的节点没有对应图块（例如折叠文件夹里的行）时不压暗，避免整个图变暗。
- `firstDirectoryCenter()` 先试标题条内一点：展开后的文件夹内部全被子块覆盖，
  原来的 4×4 网格已经找不到属于文件夹本身的位置（自检因此一度报 `no-folder`）。

## 3. 列表列宽与网格（C）

- 三张表各有一份列描述（`treeColumnSpec` / `fileColumnSpec` / `legendColumnSpec`）：
  key、表头、默认宽、最小宽、排序键。`ColumnStore.qml` 只存用户拖过的宽度。
  表头、行、可见性预算都从这里取，修掉了树表 `%` 读取文件面板宽度、文件面板读取树表宽度的问题。
- `ColumnHandle.qml` 改用窗口坐标计算增量：手柄锚在会随宽度移动的右边缘，
  原来用局部 `mouse.x` 会把手柄自身的位移抵消，于是拖动卡住/抖动。双击恢复单列默认宽。
- `TableCell.qml` 统一单元格：右缘 1px 分隔线，行底 1px 横线；表头与行共用，所以不可能错位。
  "项目"列也有了自己的竖线；数字列统一 8px 右内边距。
- 可见性：从左往右累加，固定列吃满"面板宽 − 名称列最小宽"后，右侧列自动隐藏（不再裁切）。
  名称列最小宽树 120 / 文件 110 / 扩展名 90。
- 宽度存进 `ScanSettings.columnWidths`（`{"tree":{...},"file":{...},"legend":{...}}`），
  启动时载入；列菜单新增"列宽复位"。
- 自检新增列宽拖动检查：拖树表"大小"手柄 24px 应变为 84 → 108，双击回到 84。

## 安装后需手工确认

- 三个面板分别拖列宽：跟手、不抖；双击手柄单列复位；菜单"列宽复位"全部还原；重启后保持。
- 选中文件夹 / 文件、悬停、以及选中后其余块变暗是否合意（默认压暗约 10%）。
- 层级"自动"的观感；切到 1–5 固定层级时，达到上限的文件夹显示为带标题条的单块。
