# 0.3.12 控件与回收反馈

## 变更

- 文件搜索、范围与匹配控件统一为 28 px 高，窄面板自动换行。范围支持当前目录、当前目录及子目录、整个扫描。
- 显示列入口位于 Dock 标签栏及最大化标题栏；表头右键也可打开。列选择保持弹层打开，名称始终显示，其余列可隐藏；恢复默认列同时重置列宽和可见性。
- 扩展名高亮提供图表取消按钮、图例清除入口及再次点击取消；无扩展名使用独立状态，高亮不改变文件过滤。
- 回收反馈区分明确的容量超限、取消、权限拒绝及未确认结果。执行、单项回调、中止查询分别记录；根据原路径是否存在生成提示。技术详情可展开，支持重试。
- 保留禁止静默永久删除的 Shell 回调保护。`0x00270008` 是状态码，不作为失败码显示。
