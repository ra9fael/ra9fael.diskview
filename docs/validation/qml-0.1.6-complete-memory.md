# 0.1.6 完成阶段内存修复

用户反馈 C: 扫描完成后崩溃。定位到 `ScanService::flatten`：原树仍存活时，对每个节点的 `children` 和 `name` 调用 `shrink_to_fit()`，会反复申请新缓冲区，最后完成阶段形成峰值 `bad allocation`。

本修复：

- 移除完成阶段逐节点 `shrink_to_fit()`，只清空源容器，让源树在函数退出时自然释放。
- 预先统计节点数，一次性为 FlatTree 的 8 个并行数组预留容量，避免展平中反复扩容。
- 保留 MFT 组装失败时的普通遍历回退、分段读取、批次字符串转移和无后台预览。

扫描单测、模型单测、Dock 单测及插件构建通过。尚未在用户当前 WinShun 上安装或实际跑 C: 全盘；本包需安装后针对 C: 完成阶段复测。
